# 着色器

着色器是项目里最短的程序，也是决定一切长什么样的那个程序。实验课教你把效果做出来；这一节讲
它底下的东西，好让效果能被改，而不是被抄。

## 唯一需要带走的一句

片元的工作量按**像素**算，不按物体算。一个很小的物体挂着很重的着色器，很便宜；一个全屏透明
效果挂着极简的着色器，很贵。几乎所有着色器优化的讨论都从这句话开始。
