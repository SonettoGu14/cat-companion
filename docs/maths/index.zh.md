# 数学基础

游戏代码真正用到的那点数学：向量、矩阵、坐标空间、插值，再加一点做平衡数值时会用到的概率。
这些东西会出现在每个着色器、每个脚本和每张数值表里，但没人会在你入门的那段路上专门讲。

它不是数学课。没有证明，没有为了好看而存在的记号，也不会碰引擎里用不上的东西。每页只取一个
点，指出它出现在哪，然后结束。
