# 使用说明

## 卡住的时候读，而不是替代实验课

这里的页面是给「课上有一处没落地」的那一刻准备的：着色器变成粉色了，光照公式里的点乘看不懂，
VR 术语是一堵英文墙。读完一页，回去把手上的事做完。

## 这个站不是什么

!!! warning "边界"
    - **不计分。** 这里没有任何内容被打分，也不会改变任何分数。
    - **不是课件。** Slides、handout 和课程材料属于课程本身，本站不复制它们。如果两边对
      「课程要求什么」有冲突，以课程为准。
    - **不是 assessment brief。** 作业要求、提交时间窗和评分标准以你自己模块的评估文件为准，
      不要来这里找。
    - **不替代提问。** 看完还是卡着，就在实验课上问。页面没法判断你是不是理解错了。

## 每一页怎么写

每页只回答**一个**问题。开头一句话把问题摆出来，用能说明白这件事的最小例子讲清楚，结尾是
「自检」—— 题目配可展开的答案，让你自己确认有没有落地。

多数页面是十分钟的量。超过这个长度就拆页。

## 两种语言，一个意思

每一页都有 `page.en.md` 和 `page.zh.md`。中文版是写给中文读者的，不是逐行翻译：例子一样、
顺序一样、话按中文说。两边要是有出入，那是错误 —— 以英文版为准。

术语以[术语表](../glossary/index.md)为准：点乘永远是 *dot product*，片元永远是 *fragment*，以此类推。
同一个词用两次，这正是术语表的意义。

## 发现错误

页面随课程推进维护。哪一页写错了、写不清楚、或者已经和课上讲的对不上，在实验课上说，或者在
仓库里开 issue —— 站点是公开的，欢迎纠错。

## 计划中但还没写的

每个板块自己列出计划页。还没写的页会明确标出来，不承诺时间。
