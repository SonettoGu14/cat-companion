# How to use this site

## Read it when you are stuck, not instead of the lab

The pages here are written for the moment something in class did not land: the shader is
pink, the dot product in the lighting formula makes no sense, the VR terminology is a wall
of English. Read one page, then go back and do the thing.

## What it is not

!!! warning "Boundaries"
    - **Not assessed.** Nothing here is graded, and nothing here changes a mark.
    - **Not the lecture.** Slides, handouts and the module materials are the module's own;
      this site does not copy them. If the two ever disagree about what the module
      requires, the module wins.
    - **Not the assessment brief.** Coursework requirements, submission windows and
      rubrics live in your module's own assessment documentation. Do not look for them
      here.
    - **Not a replacement for asking.** If a page still leaves you stuck, ask in the lab.
      A page cannot tell whether you have misunderstood it.

## How each page is written

Every page answers **one** question. It opens with the problem in one sentence, explains it
with the smallest example that shows the idea, and ends with a *check yourself* section —
questions whose answers you can reveal, so you know whether it landed.

Most pages are a ten-minute read. If a page grows past that, it gets split.

## Two languages, one meaning

Every page exists as `page.en.md` and `page.zh.md`. The Chinese version is written for
Chinese readers, not translated line by line: same examples, same order, natural phrasing.
If the two versions disagree, that is a mistake — the English one is the reference.

Terms are fixed by the [glossary](../glossary/index.md): 点乘 is always *dot product*, 片元 is
always *fragment*, and so on. Using the same word twice is the whole point of a glossary.

## When something is wrong

Pages are maintained as the modules run. If a page is wrong, unclear or already out of date
with what was said in class, say so in the lab or open an issue on the repository — the
site is public and corrections are welcome.

## What is planned but not written yet

Each section lists its own planned pages. A page that does not exist yet is marked as such;
nothing is promised with a date.
