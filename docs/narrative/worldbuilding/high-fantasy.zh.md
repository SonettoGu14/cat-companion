# 高魔

高魔不是「魔法很多的世界」，而是**魔法进入了制度**的世界：学院、行会、军队、税收、国教。检验的
标准不是法术多炫，而是这个世界有没有像「电」那样，把魔法当成一直存在的基础设施来组织。

这条线比听起来难得多，学生项目通常栽在同一个地方。

## 决定整个社会形态的那个问题

**谁有资格用魔法？**

诚实的答案只有几种，每一种会长出完全不同的世界。挑一个，然后推到底 —— 不要两个都要。

| 谁能用 | 社会会变成什么 | 它给你的冲突 |
| --- | --- | --- |
| 血统 —— 生来就有 | 贵族制。魔法是「为什么某些家族该统治」的理由 | 继承、正当性、生来没有魔法的贵族孩子 |
| 训练 —— 谁都能学 | 教育制度：学费、考试、阶级流动 | 谁付得起那几年、谁被淘汰、谁自学成才 |
| 契约 —— 神、灵、某个主人 | 宗教或封建权威。力量是借来的，随时可收回 | 债务、服从、主人要一样你给不起的东西 |
| 器物 —— 谁拿到谁能用 | 工业。魔法变成有供应链的商品 | 垄断、偷窃、维护、谁买得起好的那件 |

不管挑哪个，有意思的故事都在边界上：**刚好被规则排除在外的那个人**。贵族学院里没有血统的
学生；神不再回应的祭司；造得出人人都要的东西、却没有资格用的铁匠。

## 几乎没人通过的检验：为什么不是人人都在用？

如果魔法又便宜又常见，被改变的就不该只是战场，而是整个世界。

拿这四个问题问自己的设定：

1. **上下水与排污。** 有个戏法能挪水，城市就不需要水渠和水井。
2. **医疗。** 如果治疗是个法术，医院长什么样？谁付钱？
3. **交通。** 如果有传送，为什么还有路和船 —— 而且谁拥有那张网？
4. **战争。** 一个法师能轰塌城墙，为什么还有人训练步兵？

你不必在游戏里回答全部四个。但你必须答得出来，因为玩家一问，设定要么立住，要么塌掉。如果
诚实的答案是「因为剧情需要中世纪城堡」，那这个设定就是布景，架在它上面的一切都继承了同一个
弱点。

好的答案是**约束**：魔法稀缺、危险、被法律限制、被行会垄断，或者要付出拿不回来的东西。任何
一条都能保住世界的形状，同时给玩家一条可以计算的规则。

## 让魔法可玩的代价

有代价，魔法才从布景变成资源。

| 代价 | 在玩法里长成什么 |
| --- | --- |
| 每日法术位或次数 | 节奏。玩家攒着，然后一次花掉 —— 经典的 D&D 形状 |
| 会自然回复的资源 | 持续输出 vs 爆发的取舍 |
| 永久的东西 —— 记忆、寿命、某个身体部位 | 最重的选择，也是玩家事后还会聊的那种 |
| 社会代价 —— 被看见、被记住 | 潜行、名声、你敢在谁面前用 |

D&D 的法术位值得研究，哪怕你最后不用它：它是一条硬规则，让魔法显得稀缺，而稀缺才让玩家的
选择有重量。

## 三种常见失败

**魔法成了万能解。** 剧情里每个障碍都有一个法术能解决，于是剧情没有障碍，只有延迟。如果一个
法术能解决问题，那这个问题本来就不在法术身上。

**中世纪欧洲加一张法术表。** 城堡、国王、蜡烛，但没有魔法上下水。设定是戏服，玩家能感觉到：
关于魔法学到的一切，都没改变他要做的事。

**设定倾倒。** 做第一个决定之前先来四十页宇宙论。真正重要的信息只有三条：我能做什么、要付
什么、谁会拦我。

## 自检

??? question "1. 你的世界有魔法也有刀剑。给一个不是「因为好看」的理由。"
    任何指明约束的答案都算：魔法太慢、太显眼、太贵、法律只许贵族用，或者靠近铁就失效。说不出
    一条，那把剑就是戏服。

??? question "2. 你的设定里，谁不能用魔法？他们对此做了什么？"
    故事长在规则之外的人身上。如果谁都没被排除，那你还没决定谁被包含 —— 你只是决定了「世界上
    有魔法」。

??? question "3. 说出玩家为魔法付出代价的那个机制。它和设定里写的代价是同一个吗？"
    如果设定说魔法要献出记忆，游戏收的却是蓝条，玩家会信蓝条、无视设定集。机制才是玩家真正收
    到的那个设定。
