# 赛博朋克

赛博朋克不是霓虹和雨。霓虹和雨是这个世界从外面看的样子；底下真正的结构是一个关于所有权的问题：

**高技术，低生活。** 技术极大进步，但权力分配一点没改善 —— 往往更糟。赛博朋克的判断是：新技术
不会自动带来解放，它以新的控制形式到来，卖给你的人随时能把它收回去。

接受这一点，那些视觉元素就都有了理由。霓虹在那儿，是因为公共空间没了，剩下的光只有广告。

## 这个设定其实由三个问题组成

**你的身体属于谁？** 不是「能不能装义体」，而是**按什么条件装**。你的手臂是租的，维护是订阅制，
升级是贷款，而放贷的人知道你家在哪。赛博朋克最经典的形象不是「装了金属手臂的人」，而是「那条
金属手臂还不属于他的人」。

**什么还算人？** 一旦心智可以被复制、备份、编辑，身份就不再是理所当然的。一个坚信自己是原件的
副本，记忆是真的，法律地位是零。赛博朋克在这里和恐怖片接壤。

**谁在看着你？** 公共空间被私有化和监控。不被看见是一种特权，而且很贵。

## 元素与它们的结构作用

| 元素 | 作为结构在做什么 | 常见的误用 |
| --- | --- | --- |
| 义体 | 把身体变成商品：买来的能力，要维护，会失去 | 只当成一条升级树 |
| 公司 | 提供没人能替代的东西 —— 水、医疗、身份、安全 | 写成「邪恶」，却什么也不提供 |
| 网络 / 黑客 | 信息即权力：进入别人的系统 | 只当成剧情间隙里的小游戏 |
| 债务与合同 | 把每一样优势变成义务 | 买完义体就忘了它 |
| 霓虹、雨、招牌 | 气氛 —— 设定的结果，不是论断 | 被当成这个类型的定义 |

最后一行是陷阱。一个项目可以视觉元素全齐、结构一点没有，结果看起来像戏服；反过来，只有结构
没有视觉，照样能成立。

## 检验：把霓虹拿掉

去掉雨、招牌和调色。你的世界还有冲突吗？

如果答案是「公司很坏，你去打它」，这个设定就很薄：那是一个普通反派，只是打光好看。如果答案
是「玩家的身体是还不起的债的抵押品，唯一的出路是变成合同没有覆盖到的某种东西」，那你有了结构，
而且它换什么美术风格都活得下来。

## 三种常见失败

**只做皮肤。** 有反乌托邦的画面，没有规则。世界看起来很压抑，但玩家的任何行为都不受它约束。

**技术没有代价。** 义体从不坏、不需要维护、不会被收回。到这一步技术就是魔法，这个类型的全部
论点也就消失了。

**不提供任何东西的公司。** 如果打败反派之后，没有人失去水、医疗或工作，那这家公司从来就不是
结构，只是一关的 boss。

## 值得研究的例子

- **《杀出重围：人类革命》** —— 改造成为阶级标志：付得起的人和被它取代的人。
- **《赛博朋克 2077》** —— 身体是商品，城市是一个没有出口的市场。
- **《SOMA》** —— 「被复制的心智是什么」，当恐怖前提写，而不是当剧情反转用。
- **《暗影狂奔》** —— 魔法与赛博朋克同处一个世界；它证明了这些设定是可以互换的规则集，而不是
  固定的类型。

## 自检

??? question "1. 用一句话去掉霓虹讲你的提案。剩下的是什么？"
    如果剩下的是「英雄打坏公司」，那这是一张类型标签。如果剩下的是一个所有权问题、以及谁在为它
    受苦，那你有了设定。

??? question "2. 玩家的身体让他付出什么？付不出的时候会怎样？"
    有意思的答案不是扣属性，而是机制：战斗中手臂断电、升级被远程禁用、催收的人偏偏在最糟的时刻
    出现。

??? question "3. 为什么没人能干脆离开这座城市、或者拒绝这项技术？"
    设定需要一个「出口是关着的」的理由 —— 监控、债务、没有改造的人根本找不到工作。一个有可用
    出口的世界，讲的是别的事。
