# 世界观

游戏里的设定不是背景板，它是一套规则：决定角色能做什么、做这件事要付什么代价、以及谁有
权力拦住他。

最清楚的例子是魔网。在被遗忘的国度里，魔法是一张铺满世界的网，每放一个法术就等于在网上
戳一个洞，看守这张网的女神可以一次性把魔法从所有人手里抽走。《魔兽世界》用同样的思路搭出
了另一种东西：地脉、永恒之井，以及代价各不相同的魔法学派。

这些都不是「某个地方的风土人情」，它们回答的都是同一个问题 —— **魔法能做什么，谁控制它**。
故事的冲突，就来自不同的人对这个问题给出不同答案。

所以这一页讲的是：设定是结构，不是装饰。

## 最常遇到的三种设定

学生项目十有八九落在三种设定上，每一种各有一页：

| 设定 | 它围绕的问题 | 页面 |
| --- | --- | --- |
| 高魔 | 谁能用魔法，以及为什么不是人人都在用 | [高魔](high-fantasy.md) |
| 赛博朋克 | 你的身体属于谁，以及谁在看着你 | [赛博朋克](cyberpunk.md) |
| 洛夫克拉夫特式 | 你懂得太多之后会发生什么 | [洛夫克拉夫特式](lovecraftian.md) |

其他设定 —— 末日、太空歌剧、历史、现代都市、抽象 —— 干的还是下面那三件事。上面三种单独立页，
是因为它们的规则承担的结构工作最多，也最常被从表面照抄。

## 设定真正在干的三件事

三件事。一件都不干的设定，就是壁纸。

| 作用 | 具体长什么样 | 缺了它会怎样 |
| --- | --- | --- |
| 划定能力边界 | 玩家能学会的规则：传送要有视线、复活要折一条命、金库有禁制 | 所有问题都同一个答案：「用魔法」 |
| 提供代价 | 法力、堕落、献出的记忆、和某个迟早来收账的东西做交易 | 选择没有重量，剧情就没有赌注 |
| 制造冲突 | 谁控制源头、谁被切断、它失效时会发生什么 | 反派坏，因为剧本说他坏 |

第三件事是大多数设定漏掉的。魔法系统有意思，不是因为它复杂，而是因为不同的人想从它身上
拿到不同的东西。

## 硬设定与软设定

奇幻写作里有一条老规矩，通常叫桑德森第一定律：读者对一套魔法理解得越清楚，作者就越有资
格用它来解决冲突。游戏比小说更极端，因为玩家不是在旁观，玩家在算账 —— 他数冷却、数蓝条、
数弹药、数距离，而且一定会找到你没打算给的那个解法。

| | 硬设定 | 软设定 |
| --- | --- | --- |
| 规则 | 写明、自洽、可验证 | 暗示、神秘、不可验证 |
| 玩家可以 | 预判、规划、钻空子 | 被打动、感到自己渺小 |
| 适合 | 解谜、战斗、系统向玩法 | 恐怖、奇观、气氛 |
| 崩掉时 | 变成一张 Excel 表 | 结尾突然来个奇迹 |

大多数游戏要的是「硬核 + 软边」：玩家每三十秒就要操作一次的那套东西，规则得写死；让世界
显得辽阔的那部分，不必写死。

## 给你自己的设定问六个问题

写设定集之前先问。答不上来的那一条，就是你还缺的那页纸。

1. **力量从哪来？** 玩家能指出来的源头，就是故事能去的地方。
2. **谁控制它？** 谁控制源头，故事里的权力就在谁手上。
3. **用它要付什么，谁付？** 可能是使用者、可能是世界、可能是别的人 —— 但总得有人付。
4. **它永远做不到什么？** 边界才是让剩下一切变得可读的东西。
5. **社会是怎么围着它组织的？** 行会、种姓、黑市、禁令。
6. **它坏掉的时候会怎样？** 一个故事能用的失效状态。

## 检验：把设定删掉

如果删掉设定之后，玩法一点没变，那这个设定就是装饰。

试着把你的「魔网」从设计里拿走：任务还成立吗？战斗还一样打吗？如果都成立，那魔网只是设定
集里的一个名词，不是结构。反过来再试一次：把魔法的代价删掉。如果玩家的打法也一点没变，那
这个代价同样只是装饰。

真正在做结构工作的设定，会让一些事变得可能、另一些事变得不可能 —— 而且玩家两边都能感觉到。

## 三种常见失败

**设定倾倒。** 游戏开场先讲四百年前的一场战争，而玩法里没有任何东西指向它。没人记得住，只
是拖慢了玩家做第一个决定的时间。

**机制不认规则。** 设定说魔法要献出一部分灵魂，UI 上是一条营火旁就能回满的蓝条。设定变成了
一个玩家必须无视的矛盾，从那以后他也不会再信你说的其他事。

**通货膨胀。** 每开一个新区域就加一套新魔法、一种新货币、一个新等级。玩家停止学习，因为学
习不再有回报。两套深度互动的系统，胜过六套并排放着的系统。

## 它和其他几页的关系

世界观是**世界层**。这个板块的其他几页是**情节层**：[麦高芬](../mcguffin.md)是把情节往前拽的
那样东西，[英雄之路](../hero-journey.md)是它经过的形状，[高概念](../high-concept.md)是同时装住
这两者的一句话。

它们不是替代关系，一个游戏通常四样都要。最常见的翻车方式是：世界层没人设计，情节层照电影
抄了一套。

## 自检

??? question "1. 举一个设定只是装饰的游戏。删掉什么能证明这一点？"
    找那种每个区域玩法一模一样、设定只改变天空颜色的游戏。证明方式就是：删掉设定，玩家做的
    事一点不变，变的只有玩家读到的东西。

??? question "2. 你的设定说魔法有代价。玩家究竟在哪里付这个代价？"
    不在设定集里，也不在过场动画里。说得出那个机制的名字：掉下去的那条属性、被花掉的那份资
    源、永久关闭的那个选项。说不出来，这个代价就只存在于文本里。

??? question "3. 玩家问「为什么不能直接传送进金库」。比「剧情需要」更好的回答是什么？"
    结构性的回答会给出规则及其后果：金库有禁制，所以必须有人从里面开门；或者传送需要施法者
    见过目的地，所以第一幕就是去「看一眼」。规则于是变成了谜题，而不是借口。
