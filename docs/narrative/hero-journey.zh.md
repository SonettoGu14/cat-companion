# 英雄之路

约瑟夫·坎贝尔读了大量不同文化的神话，提出它们共享同一个形状：一个人离开日常世界、被考验、
回来时已经不同。克里斯托弗·沃格勒把它整理成编剧能用的十二个阶段，此后这十二个阶段就出现在
每一份提案里。

| 阶段 | 发生什么 | 在游戏里通常是 |
| --- | --- | --- |
| 日常世界 | 故事开始前的生活 | 标题画面、教程、家乡村庄 |
| 冒险的召唤 | 有件事要求你回应 | 触发的主线任务、入侵 |
| 拒绝召唤 | 主角犹豫 | *(游戏里通常删掉 —— 见下)* |
| 遇见导师 | 有人给你知识或工具 | 教程 NPC、一件道具、一个提示 |
| 跨越门槛 | 离开熟悉的世界 | 越过中枢后的第一个区域 |
| 考验、盟友、敌人 | 学会这个世界怎么运转 | 游戏的中段 |
| 逼近 | 靠近问题的源头 | 决战迷宫之前的那一段 |
| 磨难 | 最黑暗的时刻，一次失去 | Boss、死亡、背叛 |
| 报酬 | 赢到了什么 | 新能力、关键道具、真相 |
| 归途 | 带着后果回去 | 在已经改变的世界里回溯 |
| 复活 | 最后的考验，已蜕变 | 最终 Boss |
| 带着灵药归来 | 把东西带回家 | 结局、二周目、续作钩子 |

## 为什么照抄在游戏里一定出问题

- **「拒绝召唤」是电影的节拍。** 玩家按下开始键的那一刻就已经接受了冒险。写一场主角犹豫的戏，
  浪费的是游戏唯一拿不回来的东西：玩家自己的意愿。
- **该蜕变的是英雄，游戏里蜕变的是玩家。** 技能在涨、胆子在变大，而化身可以一直扁平。硬要
  给化身写一条成长弧，玩起来常常像「游戏替你长大了」。
- **「幕」和「循环」互相打架。** 游戏是一个重复几百次的循环，旅程是一条单向的线。旅程的中段
  是低谷，游戏的中段是玩家最熟练的时候，两条曲线方向相反。

照抄的结果就是一堆游戏：从村庄出发、遇见导师、最后天上出现一道光。

## 它真正有用的地方

拿它当**诊断表**，不是模板。对一个已有设计问：

- 玩家有没有离开过一个他看得懂的世界？如果没有，故事还没开始。
- 有没有东西被拿走，而且玩家感觉到了？如果没有，就没有磨难。
- 玩家做过的事有没有以改变过的样子回来？如果没有，结局只是一段过场动画。

这是节奏检查表，能抓出「80% 都是中段」的设计。

## 没有被它压扁的例子

《Journey》保留了阶段，删掉了所有台词。《Hades》把考验放进循环里，把「归途」放在两次轮回
之间。《战神》（2018）明着用这套结构 —— 而它最好的时刻，正是化身的成长弧和玩家的技术重合的
地方。

## 自检

??? question "为什么游戏通常删掉「拒绝召唤」这一阶段？"
    因为玩家已经选择要玩了。让主角替玩家拒绝，等于游戏自己不想开始。

??? question "你的游戏中段很好玩、结尾很闷。该查哪个阶段？"
    磨难和归途 —— 结尾发闷，多半是因为什么也没失去、什么也没带着改变回来，所以最后一场戏
    没有分量可花。

??? question "英雄之路是情节还是结构？"
    是结构。它规定压力该落在哪，不规定人物是谁。两个完全不同的游戏可以都走在它上面。
