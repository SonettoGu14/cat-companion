# 基础

三门课都默认你会一点向量数学和引擎常识，而三门课都没讲。这一节就是把那个默认写下来。

它不是数学课。没有证明，没有为了好看而存在的记号，也不会碰今年用不上的东西。每页只取一个
点，指出它在真实的着色器或真实的脚本里出现在哪，然后结束。
